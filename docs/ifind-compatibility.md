# iFinD MCP 与每日复盘兼容性结论

## 结论

iFinD MCP 与现有每日复盘的数据结构兼容，已通过全量验收并成为默认主数据源。

## 字段映射

| 每日复盘需求 | iFinD 工具 | 关键字段 |
|---|---|---|
| A股/港股当日行情 | THS_RQ | tradeDate、latest、preClose、changeRatio、volume、amount |
| 日/周/月 K线 | THS_HQ | open、high、low、close、volume、amount |
| 沪深300/中证500等成分 | THS_DR | 指数成份表 p03473 |
| 全A/港股证券清单 | get_stock_list | 标准代码、证券简称 |
| 交易日判断 | THS_DateQuery | A股市场 212001、港股市场 212200 |
| 财务与估值 | THS_BD | pe_ttm、pb_mrq、market_value、roe 等 |

## 与现有代码的兼容点

- A股代码可在 `sh600519` 与 `600519.SH` 间无损转换。
- 港股代码需补齐为五位并转换为 `.HK`。
- 场内 ETF 继续使用 `.SH` / `.SZ`，不能使用 `.OF`。
- iFinD 的涨跌幅字段为 `changeRatio`，成交额字段为 `amount`。
- K线采用 `CPS:2` 前复权，并以 `Days:Tradedays` 限制为交易日。

## 当前接入状态（2026-07-30）

- 已加入安全的 iFinD MCP SSE 客户端，密钥只从 `IFIND_API_KEY` 环境变量读取。
- 已加入工具清单、字段参考、实时样本和历史样本的自动兼容性检查。
- 已启用 `IFIND_REQUIRED=1` 强制门槛；iFinD 校验失败会禁止生成或发布快照。
- 已实测返回全 A 5533 只、主要指数 18 个、成交额前 200 条和 1532 个去重证券历史序列。
- 全 A 涨跌分布、成交额前 200、A 股/ETF/指数/港股快照及证券历史 K 线均优先使用 iFinD。
- 同花顺网页仅保留 iFinD 当前未提供完整映射的 90 个行业板块；腾讯仅回退 iFinD 不支持的少数跨市场代码。
- 港股历史返回代码可能去除前导零，接入层统一补足五位后再匹配，避免误报 K 线缺失。

## 发布门槛

在 iFinD 正式成为主数据源前，必须同时满足：

1. MCP 返回手册要求的核心工具；
2. A股实时样本与历史样本均有有效数据；
3. 最新交易日期与每日复盘交易日一致；
4. 全A覆盖率、指数成分数量和成交前200数量通过校验；
5. 任一关键模块出现跨日数据时拒绝发布，不使用旧值填充。
