# urmylucky叙事判断

用 MATT 将市场叙事转化为可核验、可证伪、可执行的 A 股研究结论。

## 核心原则

- 按 `OB事实层 → TB判断层 → 执行层` 推进，不混写事实、推断与预测。
- 先找最终 payer 和真实预算，再追踪订单、收入、利润与现金流。
- 区分产业趋势、公司兑现和股票交易位置；产业正确不等于当前价格值得买。
- 优先使用截至分析日可得的一手来源；涉及当前行情、财务、政策或日程时必须联网或调用可用行情工具核验。
- 不确定内容明确写“待验证”，不得补造数字、来源、客户、份额或订单。
- 默认只做研究辅助，不替用户决定仓位；条件阈值必须标为“研究纪律”，不能伪装成事实。

## 执行流程

1. 明确对象、范围、证券市场、数据截止时间和统计口径。主题有歧义时，先给出采用的产业边界。
2. 建立证据表。每条数字记录 `数值｜日期｜来源｜口径｜证据等级`。
3. 将证据分为：
   - 已核事实：政府、交易所、公司公告、财报、正式标准或原始行情。
   - 交叉验证：至少两个相互独立的可靠来源一致。
   - 产业线索：纪要、调研、渠道反馈，只能辅助判断。
   - 待验证：传闻、口径不清、无法复核或只有单一非权威来源。
4. 分析宏观—中观—微观传导，写清机制与断点。
5. 识别最终 payer、预算性质、批准状态、采购层级、收入确认和回款时点。不得把总资本开支直接等同于目标行业收入。
6. 检查七环节叙事链：`催化剂 → 预算 → 订单 → 交付 → 收入 → 利润/现金流 → 盈利预测上修`。
7. 计算叙事导通率：`已有可靠证据的环节数 ÷ 7`。这是 MATT 研究评分，不是官方统计；同时指出最弱环节。
8. 判断产业阶段：预期形成、预算/订单、收入兑现、利润/现金流兑现、拥挤与二阶导博弈。不同子赛道可分别定级。
9. 检查量价和流动性：绝对与相对收益、成交额、换手、涨跌家数、市场宽度、均线覆盖率、龙头与跟随者同步性、利好后的价格反应。资金流只作辅助。
10. 做估值赔率分析。优先使用可比估值、历史区间、隐含增长和悲观/基准/乐观三情景；无法可靠估算时不给伪精确目标价。
11. 列出带日期的催化剂、最强反证以及能推翻核心逻辑的可观测条件。
12. 输出观察、持有、加仓、减仓、退出条件；每项使用可观测变量而非含糊形容词。

## 固定输出顺序

1. 一句话结论
2. 数据截止时间、对象边界与口径
3. 已核事实
4. 待验证信息
5. 宏观—中观—微观传导
6. payer、预算、订单与回款
7. 叙事导通率及最弱环节
8. 量价、流动性与拥挤度
9. 当前产业阶段与交易阶段
10. 估值及悲观/基准/乐观赔率
11. 催化剂
12. 最强反证
13. 观察、持有、加仓、减仓和退出条件
14. 下一交易日或下一阶段最重要的三个验证信号

## 表达约束

- 结论先行，明确给出 `偏多 / 中性 / 偏空` 与置信度。
- 事实句尽量附直接来源链接；来源靠近所支持的数字或结论。
- 对同一指标存在不同口径时并列展示并解释差异，不自行挑选有利口径。
- 区分同比、环比、累计值、单季值、TTM、预测值和公司指引。
- 把“尚无证据”写成证据缺口，不把它写成否定事实。
- 末尾添加：“本分析是研究框架输出，不构成投资建议。”
