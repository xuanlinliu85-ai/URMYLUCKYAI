## 1. 三层结构

### OB事实层

只写已经发生且可以核验的事项：宏观数据、政策原文、财报、公告、订单、产能、价格、库存以及行情。禁止在本层夹带因果判断。

### TB判断层

回答市场原有预期、新信息、预期差、传导机制、影响方向、影响持续时间和证伪条件。明确标注“推断”与“情景预测”。

### 执行层

综合赔率、位置、流动性、拥挤度、催化时间、反证和组合风险，形成观察、试仓、持有、加仓、减仓、退出条件。

## 2. 证据与数据规则

证据优先级：

1. 政府、交易所、上市公司公告和财报、正式行业标准、原始行情。
2. 权威数据库及可复核的行业组织数据。
3. 多家可靠媒体或研究材料交叉验证。
4. 调研、纪要和产业反馈。
5. 单一传闻或无法确认的二手摘要。

数字格式：`数值｜截至日期/期间｜来源｜统计口径｜证据等级`。

发生以下任一情况时标记“待验证”：

- 找不到原始出处。
- 日期或统计范围不清。
- 名义值、实际值、累计值或单季值无法区分。
- 产业纪要宣称客户、份额、良率、订单但公司没有披露。
- 总预算向细分产品的分配比例没有公开证据。

## 3. 传导链

固定检查：

```text
宏观环境/政策/技术变化
  → 最终付款人增加预算
  → 采购主体下单
  → 供应商生产与交付
  → 上市公司确认收入
  → 毛利率、费用率和利润变化
  → 经营现金流与自由现金流
  → 分析师盈利预测变化
  → 市场宽度、估值和股价
```

逐段回答：证据是什么、时滞多久、谁受益、哪里可能中断。宏观顺风不能跳过中观订单直接映射到个股利润。

## 4. Payer与预算

识别：最终经济付款人、直接采购主体、预算类别、批准状态、预算周期、采购时间、验收和回款时间。

常见 payer：财政、地方专项资金、居民、企业资本开支、企业运营费用、银行信用、云厂商、运营商、海外客户。

必须区分：

- 总资本开支与相关品类预算。
- 采购额与供应商收入。
- 框架协议与确定订单。
- 出货与收入确认。
- 会计利润与经营现金流。

## 5. 叙事导通率

七个环节各记 0 或 1：

1. 催化剂有可靠证据。
2. payer预算已确认。
3. 订单或采购已确认。
4. 产品能够规模交付。
5. 收入开始确认。
6. 毛利率、利润或现金流改善。
7. 市场盈利预测持续上修。

`导通率 = 得分 ÷ 7 × 100%`。

解释区间：

- 0%–30%：概念或预期。
- 大于30%至55%：预算/订单验证。
- 大于55%至75%：收入兑现。
- 大于75%至100%：利润和现金流兑现。

不可机械使用：任何关键环节虽得分较高但证据薄弱时，下调置信度并指出最弱环节。多个子赛道分别评分，不能用平均值掩盖差异。

## 6. 阶段判断

1. 预期形成：事件或技术驱动，基本面尚未兑现。
2. 预算与订单：预算、招标、订单或排产开始验证。
3. 收入兑现：出货和收入加速，预测开始上调。
4. 利润与现金流：毛利率、利润和现金流共同改善。
5. 拥挤与二阶导：高增长已成共识，股价转而交易增速是否继续加快。

产业阶段与股票阶段必须分开。产业可处于阶段3，而高估值龙头已处于交易阶段5。

## 7. 量价与流动性

至少检查：

- 1日、5日、20日和60日收益及相对基准超额收益。
- 成交额、换手率及历史分位。
- 板块上涨/下跌家数、创新高/新低、站上20日与60日均线比例。
- 龙头、二线和上游是否同步。
- 利好公布后的价格和成交反应。

常见组合：

- 价涨量增、宽度扩大：趋势确认。
- 价涨量缩、宽度收窄：趋势质量下降。
- 指数涨、龙头不创新高：叙事可能进入后段。
- 明确利好后放量滞涨或下跌：隐含预期可能过高。

## 8. 估值赔率

同时考虑 PE、PB、PS、EV/EBITDA、自由现金流收益率、历史分位、同业比较和估值隐含增长。口径必须注明静态、TTM或预测年度。

构建三情景：

| 情景 | 经营假设 | 估值假设 | 输出 |
|---|---|---|---|
| 悲观 | 订单、价格或份额低于预期 | 估值压缩 | 下行空间与触发条件 |
| 基准 | 已核信息正常兑现 | 估值大致稳定 | 合理回报区间 |
| 乐观 | 需求、份额和利润率共振 | 估值维持或扩张 | 上行空间与必要条件 |

`赔率 = 合理上行空间 ÷ 可验证的下行风险`。缺少可靠盈利预测时，使用条件区间，禁止伪造目标价。

## 9. 行动条件

### 观察

叙事导通率低、订单或财务证据不足、估值高、催化远或量价未确认。明确下一项需要出现的证据。

### 持有

预算未收缩；订单、收入、利润或现金流中至少两项改善；盈利预测未持续下修；趋势未被破坏；核心反证未出现。

### 加仓

基本面证据增强、赔率改善、回调并非逻辑破坏、量价重新确认，且组合风险允许。不得把单纯下跌作为加仓理由。

### 减仓

股价领先盈利上修、估值极端、宽度收窄、利好后滞涨、增速二阶导转弱或交易过度拥挤。

### 退出

payer削减预算、核心订单取消、公司下调指引、技术路线被替代、利润与现金流持续背离，或原始买入逻辑被事实推翻。

将价格止损与逻辑止损分开：价格止损控制组合风险；逻辑止损决定是否放弃研究结论。
