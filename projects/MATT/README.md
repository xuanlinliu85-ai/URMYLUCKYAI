# MATT · A股研究操作系统

一个面向个人使用的 A 股研究中枢，把资料库中的 Welkin 信号管道、Nexus 产业叙事、中短期基线、结构因子、二代机 Rank 与执行风控统一到同一套可追溯流程中。

## 当前能力

- 今日决策台：八步研究与执行检查，进度和笔记仅保存在当前浏览器。
- 统一框架：数据、状态、叙事、结构、执行、复盘六层操作系统。
- 叙事实验室：用即期传播、远期导通、流动性、升贴水和多层一致性做规则映射。
- 主题地图：浏览 2026-04-24 宏观—中观—微观历史映射快照。
- 资料库：搜索经过脱敏的远端 MCP 目录索引与阅读覆盖状态。
- 使用手册：复制可直接用于后续提问的研究模板。

## 精确性约束

“精确”在本项目中指：来源、时间戳、单位、口径、样本范围和复权方式可回溯，而不是对市场方向做确定性承诺。

1. 市场数据必须带交易日与 `as of` 时间。
2. 历史快照不得标记为实时数据。
3. 同一指标冲突时先核对口径，不做无依据平均。
4. 事实、推断、规则、经验、假设、待验证使用不同标签。
5. MA20 只作为时序锚，不被表述为企业真实内在价值。
6. MCP 中的密钥、令牌和账户信息永不进入前端或构建产物。

## 每日更新建议

建议以 Asia/Shanghai 为统一时区，在收盘数据稳定后执行：

1. 冻结交易日与数据截止时间。
2. 拉取行情、成交额、上涨家数、行业/ETF/个股 Rank 和基本面更新。
3. 校验交易日、复权、样本池、缺失值、重复行与源间差异。
4. 生成 OB 层事实快照，再生成 TB 层推断，最后进入个人执行协议。
5. 保存来源清单、校验结果和失效条件。
6. 生产构建通过后发布新的私有版本。

## 本地开发

```powershell
$env:WRANGLER_LOG_PATH='.wrangler/wrangler.log'
pnpm exec vinext dev
```

生产校验：

```powershell
$env:WRANGLER_LOG_PATH='.wrangler/wrangler.log'
pnpm exec vinext build
node --test tests/rendered-html.test.mjs
```

核心数据文件：

- `public/data/macro-map.json`：带日期的主题映射快照。
- `public/data/library-index.json`：脱敏后的资料库目录索引。
- `app/framework-data.ts`：统一方法论与交互规则。

本项目仅用于研究辅助，不构成投资建议。
