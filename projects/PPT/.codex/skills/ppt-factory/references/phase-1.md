# Phase 1 V1 happy path

Build in this order:

1. Project shell and stage-based JSON/file storage.
2. Reference PPTX upload, OOXML extraction, slide PNG rendering, and contact sheet.
3. Style DNA and an editable Style Inspector.
4. Reference Strength; Minimal/Rich; Classic/Modern; Dense/Airy; Text-heavy/Visual-heavy; Financial/Technology; Low-impact/High-impact; typography, color, and layout locks.
5. Plain-text or PDF material ingestion; Storyline JSON and Slide Plan JSON.
6. Three meaningfully distinct three-slide previews: cover, executive summary, data slide.
7. Direction selection and full editable PPTX generation.
8. Final rendering, technical QA, visual QA, report, and one-click repair.

Do not add collaboration, billing, animation, enterprise governance, long-image export, preference learning, or a Golden Slide marketplace in Phase 1.

The minimum final evidence is one real reference deck, a contact sheet, Style DNA, a visible 90-to-50 Reference Strength difference, unrelated new content, A/B/C previews, an openable PPTX with at least 80% normal business elements editable, intact CJK text, and a working QA/repair report.
