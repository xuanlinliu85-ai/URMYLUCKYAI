# Calculation Engine｜口径说明

版本：`metrics-v1`

## 净值和收益

- 输入净值必须为正数，日期严格递增且不可重复。
- 区间收益：`期末净值 / 期初净值 - 1`。
- 年化收益：按实际日历天数和 `365.25` 天折算。
- 周期收益：相邻净值的简单收益率，不使用模型补齐缺失交易日。

## 风险指标

- 年化波动：周期收益的样本标准差乘 `sqrt(252)`。
- 最大回撤：历史高点至后续低点的最大跌幅；系统保存为正的损失幅度。
- 回撤恢复：最大回撤低点后第一次回到原高点的日期；未恢复时为 `null`。
- Sharpe：`(年化收益 - 年化无风险利率) / 年化波动`。
- Sortino：超额年化收益除以年化下行偏差。
- Calmar：年化收益除以最大回撤幅度。
- Historical VaR：收益经验分布的线性插值分位数，输出为正的损失幅度。
- 分母为零时 Sharpe、Sortino 或 Calmar 返回 `null`，不伪造为零。

## 分散度

- HHI：标准化权重平方和。
- Top-N 集中度：最大 N 项标准化权重之和。
- 相关性：Pearson 相关系数；常数序列或不足两个观测返回 `null`。
- 持仓重叠：两组标准化持仓权重逐证券取最小值后求和。

## 全市场筛选

版本：`fund-universe-screener-v1`

1. 先做基金代码、字段完整性、规模、历史长度、最大回撤和数据质量硬过滤。
2. 只在版本化 Comparable Group 内排名。
3. 收益、Sharpe 为正向指标；最大回撤、波动为反向指标。
4. 当前权重为 35%/30%/20%/15%，使用组内 z-score。
5. 组内样本不足时标记 `peer_group_too_small`，不跨类别拼榜。
6. 该结果只形成候选池，不等于客户 Recommendation。

## 变更规则

任何公式、无风险利率、年化周期、过滤阈值或权重变更必须生成新版本；旧结果不得原地重算覆盖。
