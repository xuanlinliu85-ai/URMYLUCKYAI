# Example Prompts

## 最常用

```text
分析一下英伟达最新一季财报。
重点告诉我哪里好、哪里不好，和财报公布前市场一致预期相比最大的预期差是什么。
再结合它过去8个季度和公司整体业务、行业、估值情况，调用分析师天团给我一个最终判断。
```

## A股

```text
分析贵州茅台最新一期财报。
用 iFinD 获取财报前一致预期和历史财务数据，核对公司公告。
重点看收入质量、合同负债、经营现金流、渠道相关指标、Guidance/市场预期，以及当前公司整体经营状态。
```

## PPT

```text
把刚才这份财报研究生成一份研究型 PPT。
不要重新研究，直接基于最终 Research Memo 和 Evidence 生成 SlideSpec，再调用现有 PPT Skill。
```
