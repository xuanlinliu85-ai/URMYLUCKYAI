# V1.5 — Earnings + Company Research

## 一句话功能

```text
分析一下这家公司最新财报。
```

系统自动完成：

```text
找最新财报
→ 获取财报前专业一致预期
→ 核验 actual / guidance / consensus
→ 识别真正预期差
→ 分析财务质量与业务 KPI
→ 分析公司整体业务、行业和估值
→ 调用分析师天团
→ 逆向挑战关键假设
→ 输出 PPT-ready 研究报告
```

## 默认不做

- 视频
- 语音
- 数字人
- 自动交易

## PPT

默认不生成。

用户明确要求时：

```text
研究报告 → SlideSpec → 现有 PPT Skill
```

因此研究报告从一开始就按“每个章节一个明确投资结论标题”的方式写，天然适合转 PPT。
