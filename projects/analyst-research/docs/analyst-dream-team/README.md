# Analyst Dream Team Codex Framework V3

一个面向 Codex 的可扩展“分析师天团”框架。

当前包含：
- 沧海一土狗
- 坦途宏观
- Kevin策略研究
- 智堡Mikko
- Spread Trading
- Analyst Dream Team Router

核心文件：

- `CODEX_START_HERE.md`：第一次交给 Codex
- `FRAMEWORK.md`：完整架构
- `AGENTS.md`：Codex 项目级行为规则
- `CORPUS_POLICY.md`：2–3年语料、长短文和作者归属权重
- `EXTENDING.md`：新增分析师流程
- `EXTENSION_API.md`：未来接口契约
- `ANALYST_REGISTRY.json`：分析师注册表
- `.agents/skills/`：实际 Skills
- `EXTENSION_KIT/`：新 Skill 模板
- `tools/self_check.py`：结构自检

目标不是模拟作者口吻，而是保存其稳定研究方法。

最新事实永远重新获取；历史语料用于框架与研究习惯。
