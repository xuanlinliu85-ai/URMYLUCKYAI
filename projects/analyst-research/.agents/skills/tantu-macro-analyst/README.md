# 坦途宏观分析引擎 Skill

安装：把整个 `tantu-macro-analyst` 目录放到 Codex/Agent 的 skills 目录中。

典型调用：
- `$tantu-macro-analyst 分析当前美国长端利率为什么上涨`
- `$tantu-macro-analyst 分析这次SOFR跳升是否意味着美元流动性危机`
- `$tantu-macro-analyst 用坦途宏观框架拆解关税、美元、美债和黄金`
- `$tantu-macro-analyst 做全球资产配置的Base/Bull/Bear三情景`

原则：历史文章负责提供方法，最新数据负责决定当前结论。
