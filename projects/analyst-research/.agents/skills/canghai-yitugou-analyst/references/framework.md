# Framework Reference

## 证据边界

- 本框架的稳定 DNA 由 `data/analysts/canghai-yitugou/analysis/DNA_V3.md` 的跨季度证据矩阵支持。
- 制度、价格/数量、相对无风险利率、财政期限结构、剩余价值/Capex 和 H 属于长期方法。
- 利率点位、风格排序、黄金/原油方向和具体政策预测属于 Current View，用最新数据重算。
- 2023 年的美元单一货币表述是建模启发式；2024–2026 年的汇率套保、主权信用和跨境资本扩展是当前完整形式。

## 核心模型
`R → M/F → S → C → H → P`

- R：制度目标与治理约束。
- M：货币价格/数量。
- F：财政、国债供给、期限结构与信用。
- S：剩余价值、定价权和部门利润分配。
- C：产业资本开支。
- H：市场状态/摩擦/资金结构。
- P：资产价格。

## 八个核心变量

### 1. PPI
将PPI视为国内制造体系中定价权和利润分配的重要“总线”，不要只理解成需求景气指标。

### 2. 价格约束 vs 数量约束
政策利率与资产负债表/准备金/信用数量是两套约束。货币松紧必须拆开看。

### 3. 财政与国债期限结构
Fed解释短端不够；Treasury发债、回购、TGA、期限溢价决定长端金融条件的重要部分。

### 4. 垄断品、原油与法币
能源和关键供给品会改变全球物价、跨境资本与货币体系约束。黄金不能只用降息解释。

### 5. 跨境资本与“全球无风险利率”
比较不同货币资产时要考虑汇率和套保成本。无风险利率是相对配置结果，而非永恒单一锚。

### 6. 剩余价值实现路径
基建、公用事业、科技、制造、消费承担不同经济功能，因此利润上限和估值弹性不同。

### 7. 资本开支
Capex连接产业趋势、总需求、信用、就业、生产率和利率。AI具有“短期需求扩张 + 中长期供给提升”的双重属性。

### 8. H
H是基本面进入价格的传导状态。高H常伴随抱团、趋势延续、估值分化；H下降时轮动和价值修复更快。

## 中国分析模板
`制度目标 → PPI/汇率/信用硬约束 → 利率价格与数量 → 上下游利润再分配 → 科技/基建/地产Capex → A股H → 股债汇房`

优先指标：PPI同比/环比和结构、工业企业利润、1Y存单/10Y国债、社融/M1/信用脉冲、USD/CNY/CNH、科技/基建/地产Capex、两融/ETF/成交集中度/风格。

## 美国分析模板
`Fed + Treasury + 私人Capex → 真实金融条件 → 实际利率/期限溢价 → 美元/黄金/科技估值`

优先指标：Fed Funds与2Y、Fed资产/准备金/RRP、Treasury发行与TGA、10Y/30Y与实际利率、term premium、CPI/PCE/工资/就业、信用利差、AI Capex/企业债/现金流。

## 黄金模板
不要使用“降息=黄金涨”的单变量逻辑。至少检查10Y实际利率、美元、原油、全球流动性、央行购金、主权/地缘信用、金油比。

## AI模板
先区分订单/Capex、收入、利润、自由现金流。
短期：`AI Capex↑ → 总需求↑/融资↑ → 中性利率压力↑`
中长期：`AI生产率↑ → 单位劳动成本↓/供给能力↑`
估值：`股价 = 未来盈利预期 / 折现率`
