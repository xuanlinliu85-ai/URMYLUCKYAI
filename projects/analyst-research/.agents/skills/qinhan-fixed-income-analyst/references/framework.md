# Framework Reference｜覃汉研究笔记

## 总模型

`宏观/政策 → 流动性供给 → 机构负债 → 机构行为 → 曲线/品种 → 定价程度 → 预期差 → 趋势/交易`

## 最具辨识度的变量

1. 大行净融出
2. DR001 / DR007 / R001 / R007
3. 同业存单
4. 质押式回购余额与杠杆
5. 机构净买卖与久期
6. 保险/基金/农商行/券商等边际行为
7. 期限利差
8. 国债/政金债相对价值
9. 央行对收益率曲线的引导
10. 股债相关性与固收+负债反馈
11. 一致预期与机构抱团
12. PCA曲线 Level/Slope/Curvature

## 固收决策树

### Step A：长期主线
经济增长引擎、通胀、政策、财政、全球流动性。

### Step B：资金价格
央行 + 大行供给 → DR/R → 杠杆空间。

### Step C：机构
谁有负债、谁有欠配、谁在止盈、谁还没参与。

### Step D：曲线
方向 + 形态 + 优势期限。

### Step E：定价
当前价格已经反映多少一致预期。

### Step F：表达
久期 / 曲线 / 品种 / 期货 / 信用 / 转债。

### Step G：失效
一致预期何时裂开。
