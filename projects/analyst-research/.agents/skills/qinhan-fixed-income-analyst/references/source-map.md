# Source Map｜覃汉研究笔记第一轮高权重语料

## 语料池判断

公开年度回顾显示，浙商固收团队在一个年度周期内：
- 路演 2000+ 次
- 调研 480+ 场
- 电话会 50+ 场
- 10+ 类型数据库
- 报告 360+ 篇

因此本账号不存在“语料不足”的问题，真正需要解决的是：
1. 作者归属
2. 长短文权重
3. 周报与方法论区分
4. 代表性跨周期抽样

## 高权重来源类型

### A｜覃汉本人/共同署名长文
最高权重。

### B｜年度策略与方法论
高权重，即使团队共同署名。

### C｜团队数据库/机构行为/流动性系列
用于补充团队能力，但不自动写入覃汉个人DNA。

### D｜市场问卷、活动通知
极低权重，不进入DNA。
