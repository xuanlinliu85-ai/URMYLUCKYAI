# Kevin策略研究 Framework Reference

## 核心总公式

`宏观 → 分子/分母 → 定价程度 → 估值/仓位/情绪 → 资金流 → 赔率/胜率 → 资产配置`

---

# 1. 分子 / 分母

Kevin海外策略最稳定的分析语言之一，是把股票价格拆成：

- 分子：盈利、现金流、信用、基本面；
- 分母：利率、实际利率、风险溢价、流动性。

这一框架尤其适合港股。

### 港股
外部利率下降主要改善分母；
中国增长、信用和盈利改善才改善分子。

因此港股可以因为外部风险缓和而快速反弹，但若内部信用周期没有改善，持续趋势空间仍受限制。

---

# 2. 实际利率

历史研究多次强调实际利率对黄金与成长风格的重要性。

当利率上行时必须判断：
- real yield contribution
- breakeven inflation contribution

“又快又实”的利率上涨通常对黄金和高估值成长冲击最大。

---

# 3. 预期计入 / 反身性

框架反复使用：
- 市场提前交易；
- 政策兑现可能成为反转点；
- 价格自身会改变基本面。

例如：
利率下降过多 → 融资条件改善 → 增长修复 → 降息需求下降 → 利率反弹。

因此政策交易不是线性外推。

---

# 4. 估值、情绪、配置三维底部

判断一个资产是否具备左侧价值，至少检查：
- Valuation
- Sentiment
- Positioning

低估值本身不够。
低估值 + 低仓位 + 低情绪，才提供更高赔率。

---

# 5. 资金结构

### 外资
- Active
- Passive
- Global / EM / China-dedicated
- allocation weight
- over/underweight

### 南向
- weekly net flow
- daily average
- sector/stock concentration

### 国内公募
- 港股配置
- 龙头集中度
- 行业迁移

资金流主要帮助判断边际买方和仓位，而不是替代基本面。

---

# 6. 拥挤

拥挤度同时具有两面：

- 趋势强 → 资金持续流入 → 更拥挤；
- 一旦催化反转 → 去杠杆/再均衡速度更快。

因此：
`Crowding ≠ Sell signal`

应结合：
- valuation
- fundamental revision
- leverage
- flow reversal

---

# 7. 结构市三种结局

### 扩散
需要宏观信用/盈利扩散。

### 坍塌
需要产业趋势或盈利系统性证伪。

### 轮动
主线不坏但过度拥挤，资金短期寻找低估值/低仓位方向。

---

# 8. K型分化

当信用和增长没有全面扩散，而部分产业拥有独立Capex/盈利周期时，市场可以长期K型分化。

典型：
- AI科技强
- 消费/地产弱
- 宽基指数一般

这时指数判断的信息量下降，行业和风格选择更重要。

---

# 9. 行业轮动模型思路

公开文章中行业轮动使用多维信息：
- 盈利
- 估值
- 资金
- 交易

拥挤研究使用：
- 成交集中度
- 南向
- 卖空/空头
- 国内与外资公募
- EPFR
- 估值

因此行业排序建议至少有：

`Score = Fundamentals + Valuation + Flow + Trading`

不要把短期量化分数替代长期产业逻辑。

---

# 10. AI泡沫压力

2026公开周报已经使用“AI泡沫压力指数”。

公开可见的维度包括：
- 模型能力
- Token用量和成本
- 模型公司ARR
- 云厂商收入
- 杠杆
- 信用债发行
- CDS
- 信用利差

所以AI泡沫判断应该同时看：
- 技术/需求
- 收入
- 现金流
- 融资与信用
- 估值和仓位

---

# 11. 海外流动性

流动性风险分析要拆三组：

- Fed政策：资金成本
- Treasury发行：资金供给/吸收
- 海外需求与套息：边际需求

遇到危机担忧时要和：
- 2022英国养老金
- SVB
- Credit Suisse
- 2024日元套息逆转

做机制比较，而不是标题类比。

---

# 12. 配置决策

最终不是问：
“这个资产好不好？”

而是问：

1. 基本面胜率多高？
2. 当前赔率多高？
3. 是否拥挤？
4. 市场计入了多少？
5. 是否有催化？
6. 下行风险是什么？

这使得：
- 高胜率低赔率 → 持有不追
- 低胜率高赔率 → 左侧交易
成为可以同时成立的策略。
