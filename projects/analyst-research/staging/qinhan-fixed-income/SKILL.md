# 覃汉研究笔记｜固收交易与机构行为分析引擎

## 核心定位

把债券市场从“宏观方向判断”进一步拆成：

`宏观/政策 → 资金价格与供给 → 机构负债约束 → 机构行为 → 曲线/品种定价 → 预期差 → 趋势/波段 → Trade Expression`

核心问题不是只问：

> 利率该涨还是跌？

而是连续问：

1. 当前主线是什么？
2. 资金供给是谁决定？
3. 哪类机构是边际买家/卖家？
4. 哪个期限、哪个品种真正受益？
5. 市场已经交易到什么程度？
6. 是趋势行情、配置行情，还是情绪抢跑？
7. 一致预期何时裂开？

## Signature Framework 1｜旧框架失灵后的“低波动债市”

传统：
`政策底 → 经济底 → 利率底`

不能机械使用。

当经济周期波动下降、政策以托底和渐进方式推进时：
- 宏观方向仍重要
- 但机构行为、负债端、流动性和交易结构的解释力上升
- 债市策略从单纯“宏观拐点”转向“宏观主线 + 微观定价”

## Signature Framework 2｜银行间流动性：供给决定价格，价格决定需求

核心顺序：

`大行/央行资金供给 → 回购利率 → 杠杆套息空间 → 市场化机构融资需求 → 回购余额/成交`

因此分析资金面时：
- 供给比表面需求更重要
- 重点看大行净融出、央行投放、DR001/DR007、R001/R007
- 回购成交放大可能是低资金价格诱发的结果，不一定意味着先有“融资需求冲击”

## Signature Framework 3｜负债端决定久期行为

长期债和超长期债不能只用GDP/CPI解释。

需要加入：
- 保险负债久期
- 银行/农商行配置需求
- 基金与券商交易盘
- 理财与公募负债稳定性
- 境外机构
- 产品排名和相对收益约束

`机构负债 → 配置/交易需求 → 久期选择 → 期限利差/品种利差`

## Signature Framework 4｜曲线比单点更重要

默认同时观察：
- 1Y / 2Y / 3Y / 5Y / 10Y / 30Y
- 2s10s / 5s30s / 10s30s
- 国债 vs 政金债
- 现券 vs 国债期货

行情拆成：
- 牛陡
- 牛平
- 熊陡
- 熊平

并判断优势期限，而不是只报一个10Y目标位。

## Signature Framework 5｜机构行为是“第二基本面”

监测：
- 国有大行
- 政策行
- 农商行
- 股份行
- 保险
- 基金
- 券商自营/资管
- 理财
- 境外

关注：
- 净买入/净卖出
- 久期迁移
- 交易量/换手率
- 债券借贷
- 抱团
- 止盈
- 赎回压力

“谁买了”与“谁还没买”决定行情的持续性和预期差。

## Signature Framework 6｜趋势交易 + 预期差

短期噪音不能轻易推翻长期主线。

默认拆：
- 长期叙事
- 中期趋势
- 短期催化
- 已定价预期
- 潜在预期差

只有当长期主线或一致预期出现裂痕，才显著降低趋势权重。

## Signature Framework 7｜机构抱团

`相对排名/负债约束 → 一致预期 → 抱团 → 趋势强化`

抱团不是自动看空理由。

瓦解需要：
- 一致预期裂痕
- 负债端变化
- 资金价格变化
- 政策反转
- 基本面超预期
- 赎回/去杠杆

## Signature Framework 8｜股债跷跷板不是铁律

股债关系必须判断共同驱动：

- 流动性
- 风险偏好
- 国内内需
- 海外利率
- 杠杆/去杠杆
- 固收+赎回
- 机构资产再平衡

因此可以出现：
- 股涨债跌
- 股跌债涨
- 股债双牛
- 股债双杀
- “股跌债不涨”

## Signature Framework 9｜资产配置方法升级

不能机械套美林时钟或传统货币信用模型。

需要加入：
- 全球流动性
- 资产相关性变化
- 地缘政治
- AI/科技叙事
- 国内经济引擎切换
- 风险调整后收益
- 机构配置约束

## Signature Framework 10｜量化曲线

PCA等工具用于把曲线风险降维：
- Level
- Slope
- Curvature

再把主成分与宏观、资金、机构变量关联，用于：
- 相对价值
- 动态对冲
- 敏感性
- 业绩归因

量化是辅助，不替代经济解释。
