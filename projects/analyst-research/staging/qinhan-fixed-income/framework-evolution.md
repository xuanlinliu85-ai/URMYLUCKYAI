# Framework Evolution｜2023–2026

本记录依据 125 条独立语料重建，其中 44 篇为可核验公开正文、42 篇达到长文标准、27 篇为覃汉具名正文。团队平台能力与覃汉个人 DNA 分层维护。

## 2023｜旧框架修正与流动性供给

- 《旧框架失灵下的债市策略思考》把低经济波动、渐进政策与传统“政策底—经济底—利率底”经验的适用边界连接起来。
- 《银行间流动性供给决定需求》提出“大行与央行供给→资金价格→杠杆需求”的顺序，形成后续资金面分析的稳定起点。
- 30 年国债、国债增发与曲线锚点把负债端和期限结构加入方向判断。

## 2024｜曲线、配置盘与技术交易体系

- 50 年特别国债、债基业绩与资产定价逻辑研究强化“配置盘/交易盘→新老券利差→优势期限”的微观路径。
- 曲线牛陡研究把央行曲线管理、大行买短卖长与短端优势连接起来。
- 布林线、波浪理论、K 线时间框架和反转形态形成可复核的技术交易模块；该模块服务于节奏与仓位，宏观和资金框架继续提供方向约束。
- 年度研究回顾证明团队覆盖利率、信用、转债和机构数据库；团队产出继续保留作者边界。

## 2025｜趋势、低波动、抱团与预期差

- 债市调整再校对、技术面校对和脉冲行情研究把长期逻辑、短期催化与交易节奏分开。
- 股债低波动研究将低波宏观与政策节奏连接为震荡环境，并用新定价因素识别破局点。
- 机构抱团研究将相对排名、一致预期、久期和瓦解条件连接起来，确立机构行为“第二基本面”。
- 反内卷、政治局会议、央行国债买卖与国内外降息研究持续采用“已定价预期—潜在预期差—期限/品种表达”。

## 2026｜第一性原理、基准约束与量化团队能力

- 第一性原理研究用短期/长期观点方向和业绩诉求构成投资行为四象限，进一步解释趋势与震荡。
- 业绩比较基准研究把指数成分变化连接到权益行业配置与债基久期迁移。
- 隔夜逆回购研究强化“投放期限、投放价格和实际资金成本联合判断”的流动性规则。
- PCA、多资产、技术分析 Skill 与专家型投研 Agent 属于团队能力演化；作者字段决定其进入个人 DNA 或团队能力层。

## 稳定个人 DNA

1. 资金供给先决定价格，资金价格再塑造杠杆需求。
2. 机构负债、相对排名和配置约束决定边际久期行为。
3. 收益率曲线、品种利差和买家结构比单点收益率包含更多交易信息。
4. 长期逻辑、短期催化、市场预期和交易节奏分别判断。
5. 技术分析用于校准节奏、位置和止盈条件，并接受宏观与资金框架约束。

## 稳定团队能力

- 利率、信用、转债、机构行为与量化数据库协同。
- PCA、技术分析自动化和多资产轮动属于可扩展团队模块。
- 团队成员署名研究进入团队能力，覃汉具名研究进入个人 DNA。

## Current View 管理

具体目标点位、月度窗口、阶段性股债方向与单次政策判断进入 Current View。每次调用采用最新数据重算，长期 DNA 继续由跨季度证据维护。
